Your attendance, on your phone

The NST Attendance extension only runs on desktop Chrome — no browser on Android or iOS supports extensions. This bookmarklet gives you the same card on your phone.

The bookmarklet

On a computer, drag this to your bookmarks bar:

📊 Attendance

On a phone, tap Copy and follow the steps below.

Easiest: set it up on your computer

If your bookmarks sync (Chrome signed in, or iCloud for Safari), do it once on the laptop and it appears on the phone.

  1. Drag the button above to your bookmarks bar.
  2. Wait for bookmarks to sync to your phone.
  3. On the phone, open my.newtonschool.co and go to any course page.
  4. Open the bookmark — in Safari, tap the address bar and pick it from Favourites; in Chrome, start typing Attendance in the address bar and tap the result.

Or set it up on the phone directly

iPhone / Safari

  1. Tap Copy above.
  2. Bookmark any page: tap Share → Add Bookmark → Save.
  3. Tap the bookmarks icon, then Edit, and open that bookmark.
  4. Rename it Attendance, delete the address, and paste what you copied. Tap Done.
  5. Go to a course page on the portal, tap the address bar, and choose Attendance.

Android / Chrome

  1. Tap Copy above.
  2. Bookmark any page with the ☆ icon, then open ⋮ → Bookmarks and edit it.
  3. Rename it Attendance and replace the URL with what you copied.
  4. On a course page, type Attendance in the address bar and tap the bookmark result.

Chrome on Android won't run a bookmarklet you tap from the bookmarks list — you have to pick it from the address bar. Safari has no such limitation.

What it actually does

It runs on the portal's own page, so it uses the session already in your browser. It reads your attendance from the same portal API the site itself uses, works out the combined lecture + lab figure per subject, and shows it in a sheet. Tap it again to close.

It refuses to run anywhere except my.newtonschool.co. Nothing is typed in, nothing is sent to any server, and no account details leave your phone. Your target and term schedule are saved on that phone only, separately from the desktop extension — there is no server to sync them through.

The bookmarklet loads its code from this page's own site, so it updates when the project does. The source is in the repository; it is built from the extension's own files, so the phone and the desktop card always agree.
